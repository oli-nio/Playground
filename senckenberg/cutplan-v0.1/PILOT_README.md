# CUTPLAN V0.1 Pilot

Direct browser application with the included Senckenberg test project.

The calculation engine and bundled HTML are unchanged from the verified original release. All prices and production selections are test scenarios, not order approvals. Known V0.1 limitation: pack pricing for raw stock is incorrect.

No Rhino source files are included.
