FORMIKAT CUTPLAN V2.2 - GitHub Pages

Open index.html through the public Pages URL or a same-origin static HTTP server.
Static UI, saved project handling, displays, solver and export run locally in the browser.
Initial page/asset download requires network access; this is not an installed offline PWA.
The 3DM native analysis requires the separate local Windows starter, Python and rhino3dm.
No source 3DM upload is offered on this public website. Open an existing .cutplan project instead.
No production, fabrication, machine or purchasing approval is implied. Prices are test assumptions.
V2.1 planning logic and source geometry are retained. Native display JSON uses lossless gzip
transport with its original SHA-256 verified before parsing. Modern DecompressionStream support
is needed for large native displays; otherwise truthful source edges and a visible notice are used.
Project changes remain in this browser; GitHub hosting does not synchronize project files.
