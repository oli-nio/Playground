# FORMIKAT Work Atlas — einfach erklärt

A new plain-language version of the V3 prototype. German prose is written for a reader without technical background, using short explanations and concrete examples. The existing V3 remains available for comparison.

Open `index.html` directly in a browser. The delivered HTML includes all CSS, JavaScript, the 23 unchanged source records and the original selected canonical source snapshot. No build, library, backend, font service or AI call is required to use it.

`EXPLAINED_CONTENT.md` contains the explanations in readable text form. `src/` preserves the small authoring source. Run `node build.cjs` to regenerate the standalone HTML and explanation document. `npm run dev` serves a local preview. Neither step installs dependencies.

## Interaction

- Six independently composed views of the work world, using SVG places and native HTML controls.
- Pan, pinch, explicit optical zoom and reset; visible native place buttons provide an alternative to map interaction.
- Selection opens a readable native dialog. Semantic levels 0–5, one-level back and full-map return explain increasingly specific questions.
- Local search for all 23 records and the glossary; separate evidence-class filters and a simple legend.
- Model A → empty → B with unestablished compatibility; the hypothetical compatibility example does not open Human Authority.
- A proposed action stops at the human boundary. Only the separately labeled hypothetical decision passage opens it. No effective authorization is issued.
- Optional 80-second story preserves Astra's ten time intervals. Pause/resume, restart, scrub, direct chapter selection and exit are available. Illustrative outcome/reuse/signal stages are labeled as examples.
- `prefers-reduced-motion` and a manual quiet-view control replace motion with static meaning. Native dialogs provide focus containment and Escape dismissal. Essential actions do not require hover.

## Limits

The page is an explanation and prototype. It runs no live retrieval, model call, capture, actual delivery, institutional write or promotion. The first roadmap proof remains pending, the capability seeds remain candidates, watch remains a bounded planning direction and F remains dormant. Private Mail/Drive originals remain outside the page. Examples involving a later solution use are hypothetical.

The spatial positions are schematic, not dates, maturity scores or proven source associations. Original negative knowledge and missing evidence are preserved. No completed comprehension study with a twelve-year-old or full assistive-technology certification is claimed.
